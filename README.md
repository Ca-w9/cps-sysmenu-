<a name="fr"></a>
## 🇫🇷 Français

Menu système Windows moderne avec des fonctionnalités complètes.

### Fonctionnalités

- **Multilingue** : Kreyòl, Français, English
- **Thèmes** : Clair et Sombre (avec sélection)
- **Raccourcis Apps** : Ouvrez les applications populaires rapidement
- **Nettoyage** : Nettoyez les fichiers temporaires inutiles
- **Outils Système** : Gestionnaire des tâches, Arrêt, Redémarrage, Verrouillage
- **Recherche Web** : Recherchez sur Google directement
- **Système de Plugins** : Ajoutez facilement des fonctions supplémentaires
- **Sauvegarde & Restauration** : Sécurisez vos paramètres
- **Assistant IA** : Intégration Ollama pour un assistant local (optionnel)

### Installation

1. Téléchargez tous les fichiers
2. Mettez tous les fichiers `.cmd` dans un dossier nommé `plugins`
3. Placez `cps_logo_icon.ico` dans le même dossier que `CPS_SysMenu.bat`
4. Exécutez `CPS_SysMenu.bat`
5. (Optionnel) Exécutez `installateur_CPS_SysMenu.cmd` pour installer sur le PC

### Fichiers Importants

- `CPS_SysMenu.bat` - Script principal
- `plugins/` - Dossier des plugins
- `cps_logo_icon.ico` - Icône de l'application
- `LICENSE.txt` - Licence MIT
- `LICENCE_FR.txt` - Licence en français
